### Neden Var Bu Şey?

Çünkü dünya çok karışık. Siyaset, ekonomi, varoluş krizleri... Ama asıl sorun ne? Doğru çay demlenemiyor. Bu simülatör o boşluğu dolduruyor. Kozmik seviyede.

### Nasıl Kullanılır?

```bash
python kozmik_cay.py
```

Sonra çay türünü yazın (veya enter'a basın). Sonra bekleyin. Çok bekleyin. Bu arada hayatın anlamını sorgulayın.

### Özellikler

- Gerçekten çalışır (test edildi, çay yanmadı).
- Rastgele absürt mesajlar verir.
- Zamanı yavaşlatır (sleep kullanarak, bilimsel olarak).
- Gizli mesajlar içerir (aramayın, bulursanız pişman olursunuz).
- Hiçbir şeyi çözmez ama moralinizi bozar.
